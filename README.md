# Aerospace Engineering Portfolio — GitHub Pages

A responsive static portfolio website built with plain HTML, CSS and JavaScript. No build tools or paid hosting required.

## 1. Personalise it
- Open `index.html` and replace `YOUR NAME`, email, city, GitHub username and example text.
- Edit the experience, research/projects, skills and education sections.
- Remove any example skill or claim that does not match your real experience.
- Put your CV PDF at `assets/CV.pdf` (or change the link in `index.html`).

## 2. Add project photos
Upload your images into `assets/images/`. Then update the matching image paths in `index.html`.
The starter filenames are:
- `taylor-couette-1.jpg`, `taylor-couette-2.jpg`
- `airfoil-1.jpg`, `airfoil-2.jpg`
- `thermal-system-1.jpg`

Use descriptive filenames and optimise large images before uploading. Keep screenshots free of confidential or unpublished data unless you have permission to share them. The image gallery opens valid images in a larger lightbox when clicked.

## 3. Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `YOUR-USERNAME.github.io` (replace with your actual GitHub username). Alternatively, use any repository and select its root folder for Pages.
2. Upload all files and folders from this project. Keep `index.html` in the published root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for the Pages deployment to finish. Your site will be at `https://YOUR-USERNAME.github.io/`.

## 4. Before sharing with professors
- Test every tab, email link, CV link, image and project link.
- Use a professional email address and a short, specific research-interest summary.
- Describe what *you* did on each project, methods used, and the outcome.
- Do not publish private contact details, proprietary work, or confidential research.
